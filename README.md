# 메타버스 성당 ✝

여러 신자가 3D 성당에 동시 접속해 **미사 순서를 함께 따라 기도**하고, 고해소에서 **고해성사를 준비**하는 실시간 웹 공간입니다.

> 온라인 참여는 주일·대축일 미사 참례 의무를 대체하지 않습니다.
> 고해 공간은 성사가 아니라 **성찰·통회·본당 고해 안내**로 구성되며, 사죄경·보속 부여 기능은 없습니다.

## 실행

```bash
npm install
npm start      # http://localhost:3000
```

- 접속자가 있으면 **10초 휴식 후 미사가 자동으로 시작**되고, 끝나면 10초 쉬고 다음 미사가 이어집니다. 모두 나가면 멈춥니다.
- `PORT` 환경변수로 포트를 바꿀 수 있습니다.

## 기능

| 영역 | 내용 |
|---|---|
| 3D 성당 | 볼트 천장·아케이드·스테인드글라스·장미창·제대·감실·독서대·신자석·고해소 2개 (외부 모델·이미지 없이 절차적 생성) |
| 스마트폰 | 듀얼 조이스틱(이동/둘러보기), 상황별 버튼, 가로·세로 화면 대응 |
| 아바타 | 사제복(장백의·전례색 제의·영대)을 입은 블록형 인물. 걷기·앉기·무릎 꿇기·인사(두 손 모음) 동작, 사람마다 피부·머리카락·제의 색이 다름 |
| 실시간 접속 | 아바타 위치·자세 10Hz 동기화, 이름표, 말풍선, 접속 인원 표시 |
| 미사 진행 | 시작 예식 → 말씀 전례 → 성찬 전례 → 영성체 예식 → 마침 예식 (20단계) |
| 진행 방식 | 진행자 없이 **자동 진행·반복**: 10초 휴식 → 20단계(짧은 단계 10초, 긴 단계 20초, 1회 약 5분 10초) → 10초 휴식 → 다음 미사 |
| 응답·자세 | 단계별 응답 버튼("또한 사제의 영과 함께." 등), 신자석에 앉으면 서기/앉기/무릎 꿇기를 자동으로 따름 |
| 연출 | 단계별 조명(말씀 전례 시 독서대, 성찬 전례 시 제대 강조) |
| 배경음 | 합성 파이프오르간 화음 + 플루트 선율 + 성당 잔향(약 4.5초) + 실내 공기음, 종소리. 미사 단계에 따라 오르간 크기 자동 조절 |
| 고해 준비 | 성령 청원 기도 → 십계명 기반 양심 성찰 → 통회 기도 → 본당 고해 순서 안내 |
| 채팅 | 200자 제한, 초당 1건 제한 |
| 인사 | 아바타를 눌러 🙇 인사하기·🕊 평화를 빕니다 → 상대에게 알림, 답례 가능(6m 이내). 평화의 인사(F키·🕊 버튼): 고개 숙여 인사 + 금빛 효과 |

### 조작

| 동작 | 📱 스마트폰·태블릿 | 💻 컴퓨터 |
|---|---|---|
| 이동 | **왼쪽 아래 조이스틱** (많이 밀수록 빠름) | `W A S D` / 방향키 |
| 둘러보기 | **오른쪽 아래 조이스틱** 또는 빈 화면 드래그 | 화면 클릭 후 마우스 |
| 앉기·일어서기 | 신자석 근처에서 나타나는 `🪑 앉기` / `🧍 일어서기` 버튼 | `E` |
| 고해소 | 고해소 앞에서 `✝ 고해 준비` 버튼 | `E` |
| 채팅 | `💬` 버튼 | `Enter` |
| 인사하기 | 다른 사람 아바타를 톡 누름 | 아바타 클릭(마우스 잠금 중이면 조준점을 맞추고 클릭) |
| 평화의 인사 | `🕊` 버튼 | `F` |
| 조작법 다시 보기 | 상단 `❓` | 상단 `❓ 조작법` |

- 첫 입장 시 조작 안내 창이 자동으로 한 번 뜨며, 접속한 기기에 맞는 탭(스마트폰/컴퓨터)이 먼저 보입니다.
- 터치 입력이 감지되면 조이스틱 화면으로, 마우스를 쓰면 컴퓨터 화면으로 자동 전환됩니다.
- 두 조이스틱은 양손으로 동시에 조작할 수 있습니다(멀티터치).

### 배경음

- 외부 음원 파일 없이 브라우저(Web Audio)에서 실시간 합성하므로 **저작권 문제가 없고 추가 다운로드도 없습니다.**
- 상단 `🔊` 버튼: 배경 오르간·성당 울림 켜기/끄기, 종소리 켜기/끄기, 음량(기본 80%). 설정은 그 기기 브라우저에 기억됩니다.
- 미사 단계별 오르간 크기는 `public/data/mass-order.json`의 `ambience` 값으로 정합니다.

| 값 | 의미 | 적용 단계 |
|---|---|---|
| `organ` | 오르간 연주 | 입당, 대영광송, 예물 준비, 하느님의 어린양, 영성체, 파견 |
| `soft` | 잔잔하게 | 인사, 복음, 신앙 고백, 보편 지향 기도, 감사송, 주님의 기도 등 |
| `silent` | 오르간 멈춤(성당 울림만) | 참회, 독서, 강론, 축성, 영성체 후 기도 |
| (미사 전) | 전주 | 미사 시작 전 대기 시간 |

- 아이폰은 **무음 모드 스위치가 켜져 있으면** 소리가 나지 않습니다.
- 탭을 숨기거나 화면을 끄면 배경음이 멈추고, 다시 열면 이어서 재생됩니다(배터리 절약).

## 개인정보·보안 설계

- **고해 메모·체크 항목은 클라이언트 메모리에만 존재**합니다. WebSocket 전송, localStorage·쿠키 저장을 하지 않으며 고해소를 나가면 즉시 지웁니다(E2E 테스트로 확인).
- 서버는 고해소의 **사용 여부(true/false)만** 알고, 누가 들어갔는지는 다른 사용자에게 공개하지 않습니다.
- 사용자 입력은 모두 `textContent`로 렌더링(XSS 방지), 서버에서 제어문자 제거·길이 제한을 적용합니다.
- 응답 버튼은 문구가 아니라 **현재 단계의 인덱스만** 전송해 임의 문구를 보낼 수 없습니다.
- 인사는 **동작 종류(bow/peace)와 대상 id만** 전송하며, 서버가 대상 존재·자기 자신 여부·거리(7m)·연속 전송(1.5초)을 검증합니다. 말풍선 문구는 각 화면에서 이름으로 만듭니다.
- 미사 진행은 서버만 정하며 이용자가 단계를 조작할 수 없습니다. WebSocket 메시지 크기는 2KB로 제한합니다.

## 구조

```
server/
  index.js   Express 정적 서빙 + WebSocket(/ws) 메시지 처리
  rooms.js   접속자·고해소 점유·입력 검증
  mass.js    미사 상태 머신(휴식 → 단계 자동 진행 → 반복)
public/
  data/mass-order.json    미사 단계(문구·자세·조명·시간) — 편집 가능
  data/examination.json   성찰 질문·기도·고해 안내 — 편집 가능
  js/scene/   cathedral.js(성당), avatar.js(블록형 사제 아바타), textures.js(절차적·픽셀 텍스처)
  js/ui/      mass.js, confession.js, chat.js
  js/main.js  진입점
tests/e2e.cjs 2개 브라우저 동시 접속 E2E 테스트 (npm test)
```

## 테스트

```bash
npm test
```

미사 자동 반복 상태 머신(단위 검사)과, Playwright + Chromium으로 위치 동기화·사제 아바타 자세·자동 미사 동기화·배경음·응답 말풍선·XSS 방어·고해소 1인 점유·메모 미전송·인사·스마트폰 조작을 검사합니다. 테스트 서버는 `MASS_SPEED=5`(5배속)로 실행됩니다.

## 배포

### Render (권장)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render 대시보드 → **New → Blueprint** → 저장소 선택 → `render.yaml`이 자동 적용됩니다.
   - 또는 `https://render.com/deploy?repo=<GitHub 저장소 URL>` 링크로 바로 시작할 수 있습니다.
3. 배포가 끝나면 발급된 주소로 접속합니다. 별도 키나 설정은 필요 없습니다.

| 항목 | 값 |
|---|---|
| 빌드 | `npm ci --omit=dev` |
| 시작 | `npm start` |
| 헬스체크 | `/healthz` |
| 플랜 | free (15분간 요청이 없으면 잠들고, 다음 접속 시 30초~1분 정도 깨어나는 시간이 걸림) |

### 일반 사항

WebSocket 연결을 계속 유지해야 하므로 **상시 실행되는 Node 서버**가 필요합니다.

- 적합: Render(Web Service), Fly.io, Railway, 일반 VPS
- 부적합: Vercel·Netlify 서버리스 함수(지속 WebSocket 미지원)
- 상태는 서버 메모리에 있으므로 **인스턴스 1개**로 운영하십시오. 다중 인스턴스가 필요하면 Redis Pub/Sub 등으로 상태 공유가 필요합니다.

## 전례문 관련

응답 문구는 짧은 환호·응답만 수록했습니다. 고백 기도·신경·감사기도 등 전문은 한국천주교주교회의 『매일미사』 또는 『가톨릭 기도서』를 참조하십시오. 성찰 질문과 기도 예시는 이 프로젝트에서 작성한 것입니다.
